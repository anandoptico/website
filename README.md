# Anand Optico

A modern, premium website for **Anand Optico** — your trusted optical store in Balasore, Odisha.

## About

Anand Optico is a leading optical retail store offering a wide range of eyewear including:

- 👓 Prescription glasses for Men, Women & Kids
- 🕶️ Premium sunglasses (including powered sunglasses)
- 🎯 Contact lenses
- 👁️ Eye testing services

We carry premium brands like **Swarovski**, **Ray-Ban**, and many more.

## Tech Stack

This project is built with:

- **Vite** - Fast build tool
- **React** - UI framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **shadcn/ui** - UI components
- **Cloudinary** - Image hosting

## Development

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
